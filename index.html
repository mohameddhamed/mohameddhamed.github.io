mini-columnar-engine

Rust • Vectorized OLAP
In-Memory Columnar Analytical Engine Inspired by Columnar Database Internals
Rust prototype for typed analytical operators with contiguous columns, bit-packed null masks and dictionary encoding. Direct-indexed aggregation uses pre-encoded dense keys. Grouped results can omit null keys and groups with only null values.
