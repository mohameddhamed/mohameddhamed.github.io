aetherkv

Rust • io_uring • AVX2
High-Throughput Asynchronous LSM Storage Engine for NVMe Flash Drives
Asynchronous Log-Structured Merge (LSM) key-value engine. Eliminates allocator contention with a generational monotonic bump arena (AtomicArena) and CAS lock-free SkipList MemTable. Features pre-allocated log segments with Direct I/O (O_DIRECT) and Linux io_uring (with clean POSIX fallback for cross-platform development), 4KB block-aligned delta SSTables, and AVX2 block-split Bloom filters.

mini-columnar-engine

Rust • Vectorized OLAP
In-Memory Columnar Analytical Engine Inspired by Columnar Database Internals
Vectorized OLAP execution engine in Rust inspired by columnar database internals (DuckDB, SAP HANA TableStore concepts). Features flat contiguous memory arrays, bit-packed null bitmasks (1 bit/row) with bit-parallel word skipping, dictionary surrogate integer encoding with O(1) predicate pruning, and direct-indexed array aggregation bypassing generic HashMaps (29.5x speedup). Vectorized via LLVM auto-vectorization patterns (8-way slice matching and 4-way independent accumulators).
