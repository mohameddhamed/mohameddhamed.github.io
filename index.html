aetherkv

Rust • io_uring • AVX2
High-Throughput Asynchronous LSM Storage Engine for NVMe Drives
Asynchronous Log-Structured Merge (LSM) key-value engine. Eliminates allocator contention with a generational monotonic bump arena and lock-free SkipList MemTable. Uses pre-allocated log segments with Linux io_uring Direct I/O (O_DIRECT) to bypass page cache pollution and inode serialization, with AVX2 block-split Bloom filters for sub-microsecond rejection.

C++20 • SIMD • Low-Latency
